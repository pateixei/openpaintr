# Bundled font fallbacks

OpenPaintR bundles regular-weight static instances of Noto Sans Arabic, Noto Sans SC, and Noto Sans JP for the interface and text previews. The font files are distributed under the SIL Open Font License 1.1. The license texts are included in this directory.

- Noto Sans Arabic is from the Noto Project Authors. [Font and license](https://github.com/google/fonts/tree/main/ofl/notosansarabic)
- Noto Sans SC and Noto Sans JP are the regional Chinese and Japanese fonts from Noto CJK. [Fonts and license](https://github.com/notofonts/noto-cjk/tree/main/Sans)
